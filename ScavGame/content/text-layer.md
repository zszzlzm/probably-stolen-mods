# 拾荒手记 · 文字层内容 v0.5

> 定位：叠加式两层里的**外层**。负责开篇、线索、结果、结算与按钮文案；网格与操作由小游戏层提供。
> v0.3 变更：D6/D7 已定——撬棍/放大镜给新用途，材料工具保留原版 10% 自动触发、只做文案；扫描仪改为被动，动作收敛到 6 个。
> v0.4 变更：线索改为区域式（左/中/右，代码加方向前缀）；补 `result.extra.more`、`end.summary.empty`。
> v0.5 变更：补 `clue.initial`（开场不预给线索）、`status.wounded_pause` / `status.resume`（受伤暂停/包扎恢复）。
> v0.6 变更：危险线索只在刚点格子的 8 邻内提示，显示「邻格 · 线索」；区域线索不再包含危险。
> v0.8 变更：线索候选只取刚点格子的 8 邻；给过线索的格子排除并顺延；类型优先于稀有。
> 语言：中文 + 英文（2026-11-18）；物品名一律用 `{0}` 注入，不在文案里写死。

## 0. 和玩法层的约定

| 约定 | 说明 |
|---|---|
| 一局 = 一晚 | 文字层按「次」推进，次数由 `ScavHelper.GetMaxScavAttempts()` 决定 |
| 线索 | 只描述刚点格子的**8 邻**；候选排除已揭示和已给过线索的格子；类型优先于稀有；方向由代码加罗盘前缀（东/东南/…）；不点名具体格，不说距离，可以说得模糊，但不能撒谎 |
| 结果 | 每次下手后一行；物品名由代码注入 |
| 固定句 | 受伤、免伤、收工、结算不参与随机，保证仪式感 |
| 不写数值 | 「剩余 5 次」「电量 3」由 UI 显示，文案不重复 |
| 装备 | 只写**带在身上**的工具；判定同 `EmporiumEntry.GetAllAfterhourOwnedItems()` |
| 工具 | 不直接增加掉落；撬棍开箱、放大镜看格、材料工具只演原版 10% 的触发 |
| 未携带 | 不显示该工具的任何文案，避免「我明明没带」的错位 |

## 1. 语气与排版

- 第二人称「你」，现在时；句号收尾。
- 一行一个信息；开篇 2–3 行，线索 1 行，结果 1–2 行。
- 单行 ≤ 26 个汉字（1280×720 下不折行）；开篇单行 ≤ 28。
- 具体名词优先，形容词最多一个；五感优先：声、味、触、温、光。
- 不写「系统提示」「恭喜获得」「判定成功」；不写概率和数值。
- 幽默要干，来自处境；每 3–5 条里最多 1 条，不扎堆。
- 不用网络梗、不用感叹号连发、少用省略号。
- 物品名用游戏内译名，通过 `{0}` 注入；文案只写「它哪里不对 / 值不值」。
- 标点：中文全角；引号用「」；破折号少用。

## 2. 工具与文字层的分工

| 工具 | 原版效果 | 文字层 / 小游戏角色 | 新增按钮 | 是否加掉落 |
|---|---|---|---|---|
| 手电筒 | 轻伤/重伤减半 | 每夜 3 次「照一下」，照亮一格并标类型；电量=次数 | 照一下 | 否 |
| 拾荒扫描仪 | 15% 双倍，每级 +5% | 被动：双倍触发时日志一句；原版双倍照旧 | 无（被动） | 否 |
| 撬棍 | 拾荒无效果 | 每局 2 个密封箱；只出普通/稀有，不出危险/空手；没带时点击不消耗下手 | 撬开（选定密封箱时） | 否 |
| 放大镜 | 鉴定/检查用 | 每夜 1 次「细看」，揭示一格确切类型；不消耗下手 | 细看 | 否 |
| 螺丝刀 | 10% 额外金属螺丝 | 触发时用「拆解」文案演出来 | 无 | 保持原版 |
| 剪线钳 | 10% 额外线缆 | 同上 | 无 | 保持原版 |
| 等离子切割机 | 10% 额外废金属 | 同上 | 无 | 保持原版 |

三条硬规则：

1. **不双倍**：材料工具的 10% 仍由 `GetRandomScavengedItem` 掷；文案只做「检测到额外物品」的表现，不再发第二份。
2. **不加次数**：撬棍把「打不开」变成「能开」，但密封箱占的是普通格位，一局总下手数不变。
3. **只给信息**：放大镜、扫描仪、手电只改变玩家知道什么、能碰什么，不改变单次掉落的期望值。

## 4. 文案池

### 4.1 开篇 `intro`

**base（6）**

1. 铁皮棚顶还在滴水。北边那堆垃圾冒着热气，是今天新倒的。
2. 垃圾场的灯只亮了一半，另一半归老鼠。
3. 风从通风井灌下来，带着铁锈和烂纸板的味道。
4. 焚化炉还温着。你借着那点光，把袖子挽到肘部。
5. 值守机器人不在。它大概又去充电了。
6. 你把袋口系紧，活动了一下手指。

**new_trash（2）**

1. 新倒的垃圾味道更冲：机油、消毒水，还有一点烧焦的塑料。
2. 这堆还没被人翻过。至少今晚没有。

**george（2）**

1. 乔治奥的人打过招呼。今晚没人会来赶你。
2. 棚角留着一盏灯。你知道是谁留的。

**careful（1）**

1. 你先看了一遍地面，才蹲下去。

**osteo（1）**

1. 膝盖响了一声。你换了个姿势，慢慢蹲下。

**tool（7，只在携带时出现，最多抽 1 条）**

- `flashlight`：手电挂在腰上。你按了一下，光柱里全是灰。
- `metal_scanner`：扫描仪在口袋里发热。它今晚还能叫几次。
- `crowbar`：撬棍别在背后。走一步，铁头就磕一下胯骨。
- `magnifier`：放大镜在胸袋里。镜片有一道旧划痕。

## 7. 组合规则（给程序）

1. **开篇**：抽 1 条 `base`，若条件满足再抽 1 条事件/特性句，最后最多抽 1 条工具句；避免与上一晚重复（记录最近 2 条）。
2. **线索**：先看刚点格子的 8 邻内有无未揭示危险；有则抽 1 条 `clue.hazard`，显示为「罗盘方向 · 线索」。没有邻格危险时，只在刚点格子的 8 邻内、未揭示且没给过线索的格子里取最高优先级（受伤 > 密封箱 > 机器 > 基础 > 空 > 静，并列随机），显示为「罗盘方向 · 线索」；具体见 [display-rules.md](../spec/display-rules.md)。
3. **结果**：按结果类型抽 1 条；同一晚同类型不重复；`{0}` 用物品本地化名替换。
4. **工具表现**：
   - 撬开：每局固定 2 个密封箱；先播 `result.pry`，再走正常掉落（不判定空手/危险）；没带撬棍只播 `status.no_crowbar`，不消耗下手；
   - 细看：播 `result.inspect.*`，标记该格，不消耗下手；每夜 1 次，用后播 `status.inspect_used`；
   - 材料工具：检测到额外材料时追加 `result.dismantle.<tool>`，不另发物品；
   - 扫描仪：不设按钮；双倍触发时追加 `status.scan_double`，不加物品；不做每回合 ping。
5. **固定句**：`result.minor/major/luck/immunity`、`end.*` 不随机，始终用第一条（或按重伤/轻伤区分）。
6. **日志**：每次下手追加一行「序号 · 结果」，物品名用本地化名；空手写「空手」，受伤写「受伤」。
7. **不撒谎**：线索由真实邻格生成；没有信息时才用 `clue.quiet`。
8. **不显示没带的东西**：任何工具文案/按钮只在携带时出现。
9. **遭遇**：已砍，不实现；[encounters.md](encounters.md) 仅作废案。

## 9. 写作检查清单

- 念出来顺口吗？有没有一口气读不完的长句？
- 有没有「你看到/你发现/你注意到」开头？删掉，直接写东西。
- 形容词超过一个了吗？删。
- 物品名是不是用了 `{0}`，没有写死？
- 这条文案提到的工具，玩家真的带在身上吗？
- 同一晚会不会和别的槽位重复？
- 玩家第二遍读到它还觉得有意思吗？
- 有没有泄露数值/概率/系统词？
- 中文标点是否全角、引号是否「」？
