# 拾荒小游戏 Mod — 计划书 v0.1

> 状态：草案。D1–D5 待拍板；本文只做设计，不写代码。
> 未解决问题、已知债与自动化验收计划见 [MEMO.md](MEMO.md)。
> 2026-11-18 决定：夜间遭遇、逐件揭示动画、配置项砍掉；音效已接三角波短音。
> 对象：深空当铺（Probably Stolen），Unity 2021.3 / Mono，内置 ModLoader + Harmony。
> 工作名：ScavArcade（暂定），中文名待定。

## 0. 一句话目标

把垃圾场「点一下按钮 → 随机掉宝/受伤」改成「一局 60–90 秒、有叙事、有操作、风险可管理」的夜间小游戏；数值主干仍长在原版系统上，不另起炉灶。

## 1. 设计支柱

1. **危险有预告**：每次伸手前都有文字线索，危险不是纯黑箱。
2. **技巧影响过程，不掀翻平衡**：小游戏把期望收益/受伤率最多移动 ±20~30%，特性、事件、扫描仪仍然说话。
3. **两层各司其职**：文字层负责「发生了什么、你为什么这么做」，小游戏层负责「你怎么做」。
4. **退出即结算，不能刷**：受伤、主动收工、次数用完都走同一套结算；中途退出不产生额外收益。
5. **可快进**：保留「快速拾荒」开关，不想玩的夜晚一键按原版 RNG 结算。

### 2.2 技术底座结论

- 纯 mod 可实现，不动场景/资源：`CustomUIManager.Window(id, title, layer)` 静态入口；`CustomUIBuilder` 有文本、按钮、图标、网格、滚动、进度条、滑块、输入框；窗口根可挂自定义 `MonoBehaviour` 逐帧跑。
- 可注册本地化（`mod/Localization/zh.csv`、`en.csv`，`ModHelper.GetLocalized`）与配置项（`ModHelper.GetConfig`）。
- 不需要改存档结构；运行期状态可在一局结束时丢弃。
- 现有 mod（`FilterPrinter`、`Pharmacy`）已跑通打包/部署，可直接复用工程骨架。

## 3. 两层设计（待 D1）

### 3.1 推荐：叠加式

```text
┌─ 拾荒窗口（overlay 层）─────────────────────┐
│ 文字层：拾荒手记（可滚动）                    │
│  · 开篇场景 / 感官线索 / 选择 / 结果日志       │
│ ─────────────────────────────────────────  │
│ 小游戏层：翻找网格（6×4）                     │
│  · 格子 / 手电 / 扫描 / 下手 / 电量            │
│ ─────────────────────────────────────────  │
│ 底栏：剩余下手 / 手电电量 / 扫描仪 / 收工      │
└────────────────────────────────────────────┘
```

文字层是「读」，小游戏层是「做」；同一窗口上下分栏，文本占 35–40%。

### 3.2 备选：双模式

- 文字模式：纯文本 + 选项，文字冒险式结算（快，约 30 秒）。
- 小游戏模式：图形网格（沉浸，约 90 秒）。
- 设置里切换；两套共用结算与数值。工作量约 ×1.5。

### 3.3 不推荐：小游戏只做表演

不影响数值、只放动画 → 玩家会觉得多此一举，也失去「在游戏里玩游戏」的意义。

## 4. 一局流程（草案）

```text
进入垃圾场
  └─ 开篇文本（3–5 行，含今晚事件与次数）
       └─ 回合 i = 1..N（N = 剩余下手数）
            ├─ 生成线索（由网格真实内容生成，允许模糊）
            ├─ 玩家动作：点格子 / 用手电 / 用扫描仪 / 收工
            ├─ 结算：物品 / 空 / 危险
            │    ├─ 受伤 → 免伤判定 → 受伤文本 → 结束
            │    └─ 安全 → 日志追加，物品入包
            └─ 电量衰减 / 暗区扩大
       └─ 结算文本（总收获 / 受伤 / 剩余次数）
  └─ 关闭窗口，回地点面板（原版「返回」仍在）
```

要点：

- 一局 = 一晚；5 次下手 = 原版 5 次尝试（特性改变次数）。
- 每次下手都调原版掉落函数，事件/扫描仪/工具/背包逻辑保持一致。
- 受伤立即结束，与 `isWoundedFresh` 语义一致；剩余次数作废（原版也如此）。
- 夜间遭遇已砍，不再插入。
- 所有「条件 → 条目」的显示规则、优先级与冷却见 [display-rules.md](spec/display-rules.md)。
- 中途关闭窗口 = 收工，不补发未使用次数。

## 5. 小游戏候选（待 D3）

### A. 网格翻找（推荐）

6×4 暗格；初始只显示模糊提示（文字层给）；点开 → 物品 / 空 / 危险；手电照一格；电量按 3 次算。

- 优点：贴合「翻垃圾」；CustomUI 网格直接支持；手电/谨慎特性有天然映射；文案好写。
- 缺点：要设计 24 格分布与难度曲线；重复游玩需要随机化。

### B. 时机条

横向滑动指针，分区：垃圾 / 材料 / 稀有 / 危险；点击定住。

- 优点：实现最省；单次约 3 秒，5 次约 15 秒；适合「快速拾荒」。
- 缺点：操作深度低；与手电/扫描仪映射牵强；容易退化成纯反应。

### C. 拖拽分拣

把翻出的垃圾拖进「卖 / 拆 / 扔」三个筐，错放扣时间或触发危险。

- 优点：有当铺分拣的职业感；可复用物品图标。
- 缺点：偏整理、不偏拾荒；拖拽与窗口拖动可能冲突；工作量最大。

建议：**A 为主体，B 作为可选的「快速拾荒」简化**（若 D5 保留快进）。

## 6. 数值映射（待 D4）

| 原版系统 | 小游戏表现 | 原则 |
|---|---|---|
| 5 次尝试（特性增减） | 5 次「下手」 | 完全一致 |
| 轻伤 5% + 1%/次 | 危险格触发原版掷骰（不是必伤）；风险可见/可推理 | 期望与原版一致 |
| 重伤 1% + 0.25%/次 | 重型危险格触发原版掷骰 | 保留低概率 |
| 手电减半伤害 | 照一格揭示类型 + 电量 3 次 | 手电仍是降险 |
| 扫描仪双倍 | 原版被动照旧；文本提示「滴了一声」 | 不重做 |
| 撬棍（原版拾荒无效果） | 解锁「撬开」：密封箱可开；密封箱只出普通/稀有物品，不含危险 | 只改可及性，不加掉落次数 |
| 放大镜（原版鉴定用） | 每夜 1 次「细看」，揭示一格确切内容 | 只给信息，不加掉落 |
| 材料工具 10% | 保留原版掷骰；触发时用「拆解」文案表现，不额外发物品 | 不与 vanilla 叠加 |
| 谨慎的拾荒客 | 危险格直接标记 | 特性仍值钱 |
| 熟练 +2 | +2 下手 | 一致 |
| 骨关节炎 | 每回合暗区扩大 / 次数递减 | 一致 |
| 肢体残缺 | 不开放 | 一致 |
| 幸运 | 免伤 / 空手 → 文本「擦边而过」 | 一致 |
| 教程免疫 | 前 N 次危险格无效 | 一致 |
| 事件 | 开篇文本 + 权重照旧 | 一致 |

### 6.1 工具规则（D6/D7 已定，2026-11-17）

- **撬棍**：给「撬开」。每局网格固定 2 个密封箱，占普通格位；只出普通/稀有，不出危险、不出空手。没带撬棍时点击只提示「没带撬棍」，**不消耗下手**。
- **手电**：给「照一下」。每夜 3 次，揭示一格的确切类型（普通/稀有/空/危险/密封箱/机器），不消耗下手；原版减伤不变。
- **放大镜**：给「细看」。每夜 1 次，揭示一格的具体物品名，不消耗下手。
- **材料工具**：螺丝刀/剪线钳/切割机保留原版 10% 自动掷骰；检测到额外物品时追加一句「拆解」文案，不另发物品。
- **扫描仪**：被动生效，不做按钮；只做双倍提示（日志一句），不做每回合 ping。
- **手电**：照一下照亮一格并标类型，就是当前范围；不做邻格扩散。

平衡红线：

- 熟练玩家一局期望收益 ≈ 原版 5 次期望 × 0.9–1.15；
- 受伤率不低于原版同等次数（谨慎特性 / 乔治奥除外）；
- 不允许「0 伤刷满 5 次」成为通用策略，否则谨慎特性贬值。

工具原则：**工具改变「信息 / 可及性」，不直接增加总掉落次数。** 密封箱占普通格位，撬开不额外掷骰；放大镜只揭示，不产物品；材料工具的 10% 仍由原版掷骰决定，文案只负责把触发演出来。

## 7. 技术方案（骨架，M0 再验证）

### 7.1 工程

- 新目录 `ScavGame/`，csproj 复制 `FilterPrinter` 骨架（netstandard2.1、IMod、manifest.xml、build/deploy 脚本）。
- 依赖：`Assembly-CSharp.dll`、`UnityEngine*.dll`、`0Harmony.dll`。

### 7.2 接点

| 目的 | 接法 |

### 7.3 UI

- `CustomUIManager.Window("scav_arcade", title, "overlay")` + `BeginGrid(6, ...)` + `AddIconButton`；日志用 `AddLabel` / `BeginScroll`；电量用 `AddProgressBar`。
- 收获揭示可借「简单开箱」的思路：先入 `afterhourInventory`，再用 `GameItemElement` + 覆盖层/价值边框播放；V1 可先简化为淡入 + 边框。
- 窗口根挂 `ScavArcadeView : MonoBehaviour`：Update 做计时/衰减/动画/脏标记刷新；不要每帧重建元素。
- 音效：`AudioManager.Instance.Play2("debris")` 等原版音效；受伤用 `debris_impact`。
- 关闭：自带关闭按钮 + Esc；关闭即「收工」。

## 9. 风险与坑

1. **刷钱点变长**：一局 90 秒 × 每天 → 疲劳。→ 快速模式 + 短句 + 可跳过动画。
2. **中途退出刷物品**：物品即时入包 + 不补次数；读档回滚整晚是否可行要在 M1 验证。
3. **与原版/其他 mod 冲突**：不改 `ScavHelper` 概率；只调公开函数；Patch 尽量 Prefix/Postfix + try/catch。
4. **谨慎特性被架空**：若能稳定避开危险，谨慎 = 无伤 + 少 2 次，仍可选但不独特。→ 后期压缩视野或加入伪装危险格。
5. **窗口拖动/点击冲突**：网格按钮点击 vs 拖动窗口；用 `CustomUIDragForwarder` 或禁用拖动。
6. **分辨率/字号**：TMP 中文换行；1280×720 最小验证。
7. **本地化不一致**：中英文案不同步 → key 表集中管理。
8. **参考实现不能直接链接**：简单开箱的 `AutoScavenge` / `CrateSearchView` / `CaseReelWindow` 是它程序集的 `internal` 类；不要引用其 DLL，只按结构重写。
