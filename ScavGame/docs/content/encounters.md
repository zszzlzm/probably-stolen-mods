# 文字层 · 夜间遭遇 v0.1（已砍，废案）

> 2026-11-18：本 mod 不实现遭遇系统；27 条本地化已从 CSV 删除。此文件仅保留作废案。

> 定位：文字层的「选择」模块，插在两次下手之间。一晚最多 1 次。
> 原则：只改**信息 / 风险 / 一格状态**，不发新物品、不新增受伤掷骰，避免和原版掉落叠加。
> 三个遭遇：塞皮科、同行拾荒者、半截机器人。

## 0. 为什么是这三个

- **塞皮科**：原版垃圾场本来就有他的送饭线（2000 千卡、乔治奥的信、警官），文字层不该装作没这个人。
- **同行拾荒者**：垃圾场是刷钱点，同行是天然的取舍：让一格换情报，还是各翻各的。
- **半截机器人**：给螺丝刀/剪线钳一个「事件里的用法」，同时不违反 D7（材料工具仍不主动发物品）。

## 1. 触发与流程

| 项 | 规则 |
|---|---|
| 时机 | 第 2 次下手之后（`attemptsUsed >= 2`） |
| 概率 | 30% |
| 上限 | 每晚 1 次 |
| 优先级 | 塞皮科（送饭窗口开启）> 同行 60% / 机器人 40% |
| 消耗 | **不消耗下手**；不改变电量 |
| 展示 | 2–4 行文本 + 2–3 个按钮；选择后 1–2 行结果；回到网格 |
| 日志 | 追加一行 `遭遇 · 塞皮科 / 同行 / 机器人` |

不满足工具/食物条件时，对应按钮**置灰并显示原因**，不隐藏——让玩家知道「带了就能选」。

## 2. 塞皮科

**条件**：`SerpicoStoryline.IsFoodWindowOpen()` 为真（已送信、未喂饱、未举报）。

**开场（2 行）**

1. 货箱后面有人在咳。你停下手里的活。
2. 一个年轻人缩在两块铁皮之间，膝盖上盖着雨布。他看了你一眼，又低下头。

**选项**

| 按钮 | 条件 | 效果 |
|---|---|---|
| 留点吃的 | 夜间背包里有 FOOD（任意卡路里） | 纯演出；原版离场时统一结算，不在这里移动物品 |
| 问一句 | — | 揭示 1 个稀有格（他指了个方向） |
| 装作没听见 | — | 无效果，只留一句余味 |

**结果**

- 留点吃的：你把袋口敞开，让他看见里面的压缩饼干。他没说谢谢，只是点了点头。
- 问一句：他抬起下巴，朝北边那堆新倒的垃圾点了点。「今天有人翻过，但没翻到底。」
- 装作没听见：你转过身，继续翻。咳嗽声跟了你一阵。
- 没吃的（按钮置灰）：你身上没有能吃的。

**注意**：不碰 `serpicoFoodKcal`、不搬食物、不触发 `OnLeaveDumpingGround`；原版怎么结算还怎么结算。

## 3. 同行拾荒者

**条件**：任意夜晚，第 2 次下手之后。

**开场（2 行）**

1. 一个裹着雨布的人从货箱后面站起来。他先看见你，没说话。
2. 他脚边放着一只已经扎好的袋子。

**选项**

| 按钮 | 条件 | 效果 |
|---|---|---|
| 让一格 | 场上还有未翻的普通格 | 随机 1 个未翻普通格变为「已被翻过」（空）；揭示 1 个随机未翻格（可能是稀有/危险/空） |
| 赶他走 | — | 无效果；他拎起袋子离开 |
| 各翻各的 | — | 无效果 |

**结果**

- 让一格：他朝东边抬了抬下巴。你让开了半步。
- 赶他走：他盯了你两秒，拎起袋子走了。
- 各翻各的：你们隔着一堆垃圾，各翻各的。

**设计意图**：让一格是真正的取舍——用一个普通格换一个位置的信息，但**不保证是稀有**；可能翻出危险，也可能只是空。

## 4. 半截机器人

**条件**：任意夜晚，第 2 次下手之后。

**开场（2 行）**

1. 一台半截机器人卡在废料里。上半身还在动，手臂一抽一抽。
2. 它的指示灯闪了两下，像在求救。

**选项**

| 按钮 | 条件 | 效果 |
|---|---|---|
| 用螺丝刀拆 | 携带 `screwdriver` | 揭示 2 个格子（1 稀有 + 1 危险） |
| 用剪线钳断线 | 携带 `wire_cutter` | 揭示 1 个危险格并标记 |
| 绕开 | — | 无效果 |

**结果**

- 螺丝刀：你卸下它的后盖。它安静了。最后一段记录标出了两个位置。
- 剪线钳：你剪断主线。它的手臂垂下去。你记下了它卡住的位置——那里有塌方。
- 绕开：你从它旁边绕过去。它的手臂还在抽。
- 没带螺丝刀（置灰）：没带螺丝刀。
- 没带剪线钳（置灰）：没带剪线钳。

**注意**：不拆出零件、不给材料——材料工具的 10% 仍由原版掷骰决定（D7）。

## 5. 效果实现（给程序）

| 效果 | 做法 |
|---|---|
| 揭示格子 | 置 `revealed = true`；稀有格用扫描仪同款高亮 |
| 标记危险 | 置 `knownHazard = true`；网格显示红色描边 |
| 变空 | 置 `looted = true`，不可再选；不产生掉落 |
| 工具判定 | `EmporiumEntry.Instance.IsAfterhourHaveOwnedItems(id)` |
| 食物判定 | 遍历 `afterhourInventory`，找 `IsGameItemType("FOOD")` 且带 `CALORIE_VALUE_TAG` 的物品 |
| 塞皮科判定 | `SerpicoStoryline.IsFoodWindowOpen()` |
| 不消耗下手 | 遭遇不改 `attemptsUsed`、不改电量、不调伤害函数 |

## 7. 待确认

- **触发率**：30% 是否太高？一晚 5 次下手，30% 大约每 3 晚遇到 2 次。
- **是否消耗下手**：推荐不消耗；如果你觉得白拿情报太便宜，可以改成消耗 1 次下手。
- **塞皮科「留点吃的」**：推荐只做演出（原版离场统一结算）；如果你要真的扣食物，需要改原版结算，风险高。
- **同行「让一格」换情报**：推荐随机揭示（不是必出稀有）；如果觉得太亏，可以改成「让一格，必得一件普通物品」。
