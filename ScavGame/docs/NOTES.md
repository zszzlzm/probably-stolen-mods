## 这一版怎么变

### 0. 原版预生成

- 进本时 24 格全部生成；点击只结算已经生成好的结果。
- 空格只来自负幸运（或幸运救下受伤）；幸运不是负数时整晚可能没有空格，这是原版行为。
- 受伤用进本时的 5%/1%，不随已下手次数增长。
- 免疫 > 0 时不生成对应类型的受伤格；免疫次数按点击次数递减。
- 首件是六类物品的格子标「箱」，没撬棍不能开；首件是 tier1/2 模组的格子标「机」。

### 1. 点过的格子

点开/揭示后，格子会显示：

| 标记 | 含义 | 颜色 |
|---|---|---|
| 物 | 普通物品 | 米白 |
| 空 | 空格 | 灰 |
| 危 | 危险格 | 红 |
| 箱 | 密封箱 | 金 |
| 机 | 机器 | 蓝 |

额外掉落不再单独生成「多」格：一次出多件时，格子仍然是「箱 / 机 / 物」，只是标记变绿。被线索指到、且这格有额外掉落时，会直接把该格标成绿色的箱/机/物。

手电「照一下」每夜 3 次，电量就是这 3 次；状态栏显示「手电：3/3」，剩 1 时提示「手电暗了一下」，到 0 置灰。照一格显示类型，不消耗下手。放大镜「细看」每夜 1 次，显示具体物品名，也不消耗下手。两者都会留下类型标记，之后还能点。扫描仪仍是被动双倍，触发时日志追加「扫描仪又叫了一声」，不设按钮，也没有每回合 ping。螺丝刀/剪线钳/切割机触发 10% 额外材料时，追加对应的「拆解」句，不另发物品。

音效是 5 个自生成的三角波短音：开窗/工具（ui）、点击（blip）、稀有/多件（coin）、受伤（hurt）、结算（end）。

### 2. 受伤暂停

- 受伤时不再直接结算，窗口进入暂停：格子变灰、状态行显示「包扎后继续」。
- 用绷带把 `isWoundedFresh` 消掉后，`ArcadePulse` 会在下一帧自动恢复：格子重新可点、日志追加「包扎好了。还能继续。」。
- 剩余下手保留；原版伤害/幸运/免疫仍然照旧。
- 如果受伤时已经 0 次下手，才直接结算。
- 同晚关掉窗口再开不会重新生成；离开垃圾场再进才重生成（次数不刷新）。

### 3. 开场不预给线索

- 打开窗口时线索行只显示「从哪一格开始？」。
- 第一次下手之后，才给出线索。
- 每条线索只抽一次，并按点击的格子序号存起来；关窗重开、包扎恢复只回放原文，不会重抽，也不会多标绿一个格子。
- 细看不会触发线索刷新；下一次真实下手后才会。

### 4. 线索改成罗盘方向

- 不再出现「左边 / 中间 / 右边」。方向现在是从刚点的格子指向线索来源格的罗盘方位：东 / 东南 / 南 / 西南 / 西 / 西北 / 北 / 东北。
- 危险：只检查刚点格子周围 8 格，有未揭示危险才报，例如「东南 · 那袋东西动了一下」。
- 其它类型：只在刚点格子周围 8 格、未揭示、且没给过线索的格子里取总价值最高（并列随机），报它相对你的方向。
- 给过线索的格子会排除，自动顺延第二/第三候选；8 格都排完才报「没什么动静」。
- 同一格只产生一次线索；关窗重开或包扎恢复只是把这条线索原文放回去，不会重新抽。
- 类型优先：密封箱/机器即使价值 ≥70 也报箱/机，稀有只给基础格/多件格。
- 如果这一格还有额外掉落，格子会变成绿色的箱/机/物，线索报「不止一件」。
- 邻格干净时不会报任何远处危险。

### 5. 右键手动标红

- 右键点一个未揭示的格子：格子变红、显示「!」；再右键恢复。
- 不消耗下手，不改变真实类型，不影响线索。
- 翻开该格后红标自动清除；关窗重开会重置。

### 6. 收起「收工 / 关闭」按钮

- 窗口底部不再有「收工」和「关闭」；只保留「细看」（带放大镜时）。
- 点游戏原版「返回」时，小游戏窗口自动关闭，已拾到的物品照常带回，不额外弹结算。
- 窗口右上角 X 仍然只关闭窗口；同晚重开不重生成，离开垃圾场再进才重生成。

## 明确不做

- 夜间遭遇（塞皮科/同行/机器人）：砍掉。
- 逐件揭示动画：砍掉。
- 配置项（快速模式/文本速度/难度）：不做；关掉 mod 就回原版快速拾荒，难度沿用游戏自带。

## 要重点看

1. **点格标记**：点完一格后，标记和颜色是否保留；重开窗口后应保留，不应重新生成。
2. **受伤暂停**：受伤后格子是否变灰、状态行是否出现「包扎后继续」；用绷带后是否自动恢复、剩余次数是否保留。
3. **开场线索**：刚打开时是否只显示「从哪一格开始？」，不再直接报危险。
4. **罗盘方向**：点一格后，线索前缀应是「东/东南/南/西南/西/西北/北/东北」，不应再出现「左/中/右」；8 邻格内有危险时方向应指向危险格。
5. **右键标红**：右键未揭示的格子是否变红显示「!」，再右键恢复；是否扣下手。
6. **布局**：底部「照一下 / 细看」两个按钮是否挤，日志有没有顶掉网格。
7. **返回联动**：窗口开着时点游戏原版「返回」，小游戏是否立即消失、能正常回到店里。
8. **手电照一下**：带手电时底部是否出现「照一下 · 3」、状态栏「手电：3/3」；点一格是否显示类型、不扣下手；剩 1 是否提示；0 次是否置灰。
9. **放大镜细看**：是否显示「细看 · 1」；点一格是否直接报物品名；1 次后是否置灰。
10. **额外标签**：多件格子是否不再显示「多」；线索指到多件格时是否变成绿色箱/机/物，并报「不止一件」。
11. **扫描仪双倍**：带扫描仪触发双倍时，日志是否多一句「扫描仪又叫了一声」；没触发时不应出现。
12. **材料拆解**：带螺丝刀/剪线钳/切割机触发 10% 额外材料时，是否出现对应拆解句；普通同 ID 掉落不应误报。
13. **音效**：开窗、点击、稀有/多件、受伤、结算是否各有一声短促三角音；不应盖掉原版 debris 太多。
14. **英文**：切到英文后不应出现原始 key 或中文；格子标记 `H/E/B/M/I` 与图例可读；长文本不溢出。

日志搜 `[ScavArcade]`，应能看到：

```text
[ScavArcade] paused for bandage, attempts=N
[ScavArcade] resumed, attempts=N
```
