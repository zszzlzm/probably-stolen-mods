试剂可售 / Reagent Resale  v1.0.0
=====================================

拆包后的化学试剂，在原版里既没有价格也没有买家：整包装的化学用品能卖，
拆成瓶子就只能自己用或者烂在包里。这个模组把它们接回市场。

做了什么
--------
1. 计价：按游戏自己的水价费率（40 信用点 / 1000 ml）给试剂瓶定价。
   250 ml 的酸 / 碱 / 酒精 ≈ 10 点内容价值，加上瓶子基价 3，成交价约 13。
   拿不准就悬停看一眼，价格行会显示。
2. 可售：给试剂瓶补上"化学用品"类型，于是毒药买家、药品商、管制化学品
   买家都会收（和整包化学用品走同一套买家）。
3. 修正 −90%：原版把任何非水液体都判成"沟渠水"（纯度兜底到最低档），
   价值直接砍掉九成。模组把试剂瓶移出水质评级，价格才按真实费率算。

经济上是什么位置
----------------
普通化学用品包 50 点，拆出来的 5 瓶按这个价格卖约 61 点（+22%）。
这个差价落在游戏自带的批发折扣区间（供应商卖你 -15%~-33%）里，属于正常
贸易利润，而不是新印钞机——化学品包没有批量补货渠道。

如果你把试剂做成药（澄心剂、消痛片……）再卖，赚得比散装多得多。
所以拆包做产品仍然是最优解，"卖散装"只是止损退路。

安装
----
1. 关闭游戏。
2. 把 ReagentResale-v1.0.0 整个文件夹放进：
   <游戏目录>\Mods\
   （Steam 库右键游戏 → 管理 → 浏览本地文件，然后进 Mods）
3. 启动游戏，模组列表里应该出现"试剂可售 / Reagent Resale"，勾选启用。
   首次启用会要求你审核指纹，确认即可。
4. 读档。已有的试剂瓶会在第一次被检查时自动补票（卖出判定 / 打开提示）。

注意
----
* 游戏的拆包弹窗仍然写着"这将会把物资拆解为不可交易的化学品"。
  装了这个模组之后这句话不再成立——我们还没有覆盖这句文案，
  因为原版把文本打包进了 Unity 本地化资源，改动它的影响面比这个模组本身大。
* 模组只改物品的价格与类型，不动存档结构，可以随时卸掉。
  卸掉后物品上会留一个无害的未知标记（CHEM_RESALE_REAGENT_TAG），不影响游戏。
* 试剂瓶不能再塞进自动售货机（原版对"化学用品"类型就是这么限制的）。

兼容

游戏版本 0.46D。与其它不修改化学/交易系统的模组基本无冲突。
