还原剂蕨 / Reduction Fern  v0.1.0
============================================================

【关于这个模组】
新增一种合法作物「还原蕨」：孢子种进水培槽，长成后割下叶片搅碎，就是还原剂。
还原剂平时只能从「化学用品（管制）」里拆出来，一次没几毫升；有了这株作物，
奥克莫吸这类合成第一次有了能自己种、不用碰违禁品的来源。

  · 还原蕨孢子：28 信用点；网络界面花 450 信用点解锁「还原蕨孢子」，一次给 2 颗
  · 还原蕨叶：按植株健康度出三档 —— 小叶 20.5 克 / 标准叶 40 克 / 大叶 75 克
  · 叶片同时属于「化学用品」和「材料」：可以直接卖，也能搅碎取液
  · 天生特质：耐旱 I、产出还原剂 I；生长进度 26，一茬 8 片叶
  · 每片叶 0.25 ml/克还原剂 + 特质加成；标准叶一茬约 120 ml，满血大叶约 190 ml
  · 孢子与叶片都没有违禁标签，卖店、投料、上柜台都不招麻烦

【安装】
1. 把压缩包里的整个 ReductionFern-v0.1.0 文件夹放进：
       <游戏目录>/Mods/
   （Steam 版一般是 ...\steamapps\common\Probably Stolen\Mods\，
     放好后路径形如 Mods\ReductionFern-v0.1.0\manifest.xml）
2. 启动游戏，打开「模组」菜单，找到「还原蕨 / Reduction Fern」，点「审核并启用」
3. 启用后可能需要重启游戏一次
4. 进游戏 → 店铺电脑 → 网络界面 → 解锁「还原蕨孢子」（450 信用点，无前置）

【注意】
· 本模组不含任何 Steam / 文件 / 网络能力声明
· 与 Hydroponic Seed Preview 兼容：种子进槽后的预览显示蕨叶立绘，而不是孢子图标
· 中途卸载后，存档里已有的孢子和叶片会变成未知物品，建议先把它们处理完再卸
· 试玩版创意工坊不可用，但本地 Mods 文件夹安装仍然有效
