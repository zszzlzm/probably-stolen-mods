# 还原蕨 素材设定（Art Spec v0.1）

> 对象：[PLAN.md](PLAN.md) v0.3 里的 5 张精灵图。
> 环境：Probably Stolen 0.46D，原版精灵全部从 `resources.assets` 导出（`refs/vanilla/`），色板取自这 26 张原版种植图。

## 0. 三档叶子是什么关系

梦帽菇的做法是**同一个物品 ID、三种尺寸变体**：`CreateSmallDreamCap` / `CreateDreamCap` / `CreateLargeDreamCap` 都取 `dream_cap` 这个条目，只是换精灵、换重量（20.5 / 32.5 / 75 g）和形状（1×1 / 1×2 / 2×2）。还原蕨照抄这个结构：

| 变体 | 物品 ID | 精灵 | 画布 | 占格 | 重量（待 PLAN 定） |
|---|---|---|---|---|---|
| 小叶 | `restoring_fern` | `restoring_fern_s` | 16×16 | 1×1 | 20.5 g |
| 标准 | `restoring_fern` | `restoring_fern` | 16×32 | 1×2 | 40 g |
| 大叶 | `restoring_fern` | `restoring_fern_l` | 32×32 | 2×2 | 75 g |

占格由画布尺寸和每格中心点的 alpha 决定（§1），所以三张图的画布尺寸必须严格是 16×16 / 16×32 / 32×32，不能靠「画小一点」来变成 1×1。

> 注：PLAN v0.4 已按这三档重算（还原剂 0.25 ml/g、价值 0.45 信用点/g）：小叶 10.1 ml / 9 信用点、标准叶 15 ml / 18、大叶 23.75 ml / 34；三档同 ID、按血量拆，见 `PLAN.md` §3.3 与 D7。

## 1. 通用规则（5 张图都适用）

| 规则 | 值 | 依据 |
|---|---|---|
| 画布尺寸 | 16 的整数倍（16×16 / 16×32 / 32×32 / 48×64） | 原版所有种植图都是 |
| 内容留边 | 四边各 **1 px** 透明；叶子类底边可贴边（原版 `dream_cap_s`、`fillerweed` 底边 margin = 0） | `tools/measure_margins.py` |
| 背景填充 | 全画布铺 `(0,0,0,3)`，**不能全透明** | 见下方「为什么必须有这层」 |
| 锚点 | 中心 `(0.5, 0.5)` | 原版 `m_Pivot` 全为 0.5 |
| 光源 | **左上**：亮部在左上缘，暗部在右下缘 | `dream_cap`、`kotton_plant` 的明暗方向 |
| 描边 | 外轮廓 **1 px `#292234`**；内部不描边，用暗色块分界 | `dream_cap` 的深色外缘 |
| 抗锯齿 | **禁止**。主体像素 alpha 只有 0 / 255，不画半透明 | 原版像素画 |
| 色数 | 单张 ≤ 8 色（含描边和背景填充） | `dream_cap` 8 色、`hydroreed_filter` 10 色 |
| 文字 | 不画任何文字/logo/数字 | — |
| 阴影 | 不画地面投影、不画底座以外的东西 | 原版物品图没有投影 |

**为什么必须有这层 alpha=3 的底**：物品占几格不是由「形状」决定的，而是 `SetSpriteAndShapeFromMod` 按 16×16 格**采样每格中心点的 alpha**（`GameItem.cs:404-415`），`alpha > 0` 就记一格。原版每张物品图都铺满 `(0,0,0,3)`，所以 16×32 的梦帽菇永远是规规矩矩的 1×2，不会因为叶子细而在背包里缺角。我们要照做，否则一片细蕨叶可能只占半格、摆不进容器。**由此推论：内容留边 1 px 不影响占格，但底必须铺满。**

## 2. `restoring_fern_seed` — 孢子袋（16×16，1×1）

| 项 | 设定 |
|---|---|
| 读法 | 和原版种子一样的**方袋**：深色描边、上下棕色压边、米白内页，内页正中一枚青绿色蕨叶图标 |
| 构图 | 直接沿用原版种子袋模板（`dream_cap_seed` 的 16×16 排布）：第 1 行 1 px `K` 外框；第 2 行 `w/C` 交替高光；第 3 行 `M/r` 压边；第 4–11 行内页 `w`，左右 `C` 边；第 12–13 行 `M`/`r` 底压边；四边留 1 px |
| 图标 | 内页中央 5×7 的蕨叶：`T` 主脉、`B` 叶对（上下各一对）、`G` 最外侧叶尖；共 4 色（`T` `B` `G` + 底 `w`） |
| 色板 | `K` `w` `C` `M` `r` `T` `B` `G`（8 色） |
| 描边 | 方袋外框 1 px `K`，内页不描边 |
| 参考 | `dream_cap_seed`（袋型/压边）、`hydroreed_seed`（内页图标位置） |
| 模型输入 | refs = [dream_cap_seed 放大版, hydroreed_seed 放大版]；512×512 |
| 关键点 | 16×16 下**不要**画玻璃瓶/瓶盖——原版两种种子都是「方袋 + 图标」，画瓶子会和它们并排时明显不是一套；模型只用来定图标形状与配色，像素按模板手排 |

**验收**：8 色、16×16、内容 14×14；内页图标在 1× 下能看出「一竖 + 两对叶」；与 `dream_cap_seed` 并排时袋型一致。

## 3. `restoring_fern_s` — 小叶 / 卷叶（16×16，1×1）

| 读法 | 一个还没展开的**拳卷叶**（fiddlehead），盘成半圈，底部贴边 |
| 构图 | 主螺旋占 10×12，右下角留 1–2 px `D` 阴影；底部 2 px 的 `T` 短茎贴到画布底边（margin 0，像 `dream_cap_s`） |
| 色板 | `K` `B` `T` `L` `D`（5 色，全青系，呼应还原剂的蓝绿色） |
| 描边 | 螺旋外缘 1 px `K`，内圈不描 |
| 参考 | `dream_cap_s`（1×1 的体积感）、`web_01` 卷叶照片 |
| 模型输入 | refs = [dream_cap_s]；512×512 |

> 2026-11-22 已按此定稿：`refs/final/restoring_fern_s.png`（模型 seed 111 出卷叶 → `pixelize2 --simple` 直缩到 16×16 → 补 1 px 描边）。结论：**轮廓简单的图可以直接缩**，不需要像种子那样重排模板；`--simple` 模式不做 2×2 多数表决，能保住 1 px 的茎。

## 4. `restoring_fern` — 标准叶（16×32，1×2）

| 项 | 设定 |
|---|---|
| 读法 | 一株**小叶丛**：中间一片主复叶最高，左下压一片短暗叶、右侧后面再压一片暗叶，底部收进 4×2 的根座——和 32×32 大叶的「叶束」是同一套语言，只是这个尺寸放不下五枝 |
| 构图 | 主叶：中脉 x 8→7（`x_profile` 让中脉略带弯，不是死直），y=3→26；叶片每 3 行一对、共 8 对，**上面一行 `G`、下面一行 `g` 且外端缩 1 px**（叶尖只剩 1 px、中脉两侧留暗 V 缺口）；叶长从下往上 2-3 / 3-2 / 4-3 / 4-4 / 5-4 / 4-5 / 3-3 / 2-2，**左右刻意不等** |
| 纵深 | 右侧暗叶（`g` 叶面 + `g` 叶背、`g` 中脉，x=9，y=6→26，叶长 1–2）先画，只在中脉右侧露 1 px 暗边；左下短叶（`g` 同色，x 6→4，y=13→26，叶长 1–2）也是先画，形成叶子丛的底部体积 |
| 错行 | 右叶整体下移 1 行（`stagger=1`），去掉镜面对称 |
| 色板 | `K` `G` `g` `T` `B` `L` `D`（7 色） |
| 描边 | 外轮廓 1 px `K`；叶与叶之间不描线，靠 `g` 行与 V 形缺口分开 |
| 参考 | `web_02`（叶序）、`hydroreed_filter`（青绿色板 + 立姿）、`fillerweed`（16×32 的密度上限） |
| 模型输入 | refs = [web_02, hydroreed_filter 放大版]；512×1024（只用来定形状，像素手排） |
| 关键点 | 16 px 宽放不下「五枝并列」——会并成一团；改成**一片主叶 + 两片暗叶**。叶片必须是 1 行 `G` + 1 行 `g` 的实体，不能留 1 px 透明缝（透明缝会被外描边填成黑线，整张图变成网格） |

**验收**：内容 bbox ≈ 12×27，四边 ≥1 px；从 1× 能看出「一片主叶 + 左下暗叶」；`K` 只出现在最外圈；叶间无透明洞。

**验收记录**

> 2026-11-22 按大叶的新标准重做并定稿：`refs/final/restoring_fern.png`（16×32、7 色、body 226、四边各 1 px）。
> 脚本 `tools/draw_fern.py` 只描述几何；`Frond` / `draw_frond(stagger=)` / `rim_light()` 在 `tools/frond_art.py`，`Grid` / `fill_seams()` / `outline()` 在 `tools/pixel_art.py`，两张大叶小叶共用。
> 返工记录：旧版是「一根直中脉 + 7 对等长叶」，干净但空。新版把中脉掰弯、叶长左右错开、并把两片暗叶先画在后面填缝，视觉上才有叶丛的体积。模型稿 `refs/gen/fern_s203.png` 仍只作形状参考（直接缩放会糊）。

## 5. `restoring_fern_l` — 大叶（32×32，2×2）

| 项 | 设定 |
|---|---|
| 读法 | 一丛**扇形叶束（bouquet）**：五枝都从 x 13–19 的窄根座长出来，越往上越散，形成一个底部聚拢、顶部张开的蕨丛 |
| 构图 | 前层三枝（`G` 叶面 / `g` 叶背）：中枝 x 16→15、y=3→27（中脉略弯，`x_profile`）；左枝 x 15→7、trip y=9；右枝 x 17→25、tip y=10。后层两枝（`g` 叶面 / `D` 叶背 + `D` 中脉）在 x 14→5 / 18→26，y≈7→27，另有一枝暗枝直接压在中枝后面填缝 |
| 叶片 | 每 3 行一对，长度 1–5 且左右不同（如左枝外侧 5 / 内侧 3），下方一行 `g` 比上方缩 1 px → 叶尖 1 px、中脉两侧有暗 V 缺口。**不要用 6 px 等长的宽叶片**：那会变成「空荡荡的横梯子」 |
| 错行 | 右叶整体下移 1 行（`stagger=1`）；相邻枝的叶对行错开 1–2 行；否则整张变横条纹 |
| 根座 | 4×3 px `D`（x 14–17，y 27–29） |
| 色板 | `K` `G` `g` `T` `B` `L` `D`（7 色） |
| 描边 | 外轮廓 1 px `K`；枝间不描线，靠背景缝 + 后层暗枝分开 |
| 参考 | `dream_cap_l`（32×32 的体积）、`nutrifruit`（32×32 的构图重心）、`web_06`（树蕨扇形） |
| 模型输入 | 未出图——手排 |
| 关键点 | 大叶「变大」靠**枝数与张开角度**，不是靠把每片叶子加宽；中间那枝必须和其它枝同一尺度，否则会变成一个又大又空的主角 |

**验收**：内容 bbox ≈ 24×26，四边 ≥1 px；能数出 5 枝（3 亮 2 暗）；`G` 面积 ≥ 标准叶的 2 倍（实测 body 421 vs 225）。

**验收记录**

> 2026-11-22 已按此定稿：`refs/final/restoring_fern_l.png`（32×32、7 色、body 421）。
> 手排脚本 `tools/draw_fern_l.py`，共用 `tools/frond_art.py`（`Frond` + `draw_frond(stagger=, notch_min=)` + `rim_light()`）与 `tools/pixel_art.py`。

## 6. `restoring_fern_p` — 水培生长立绘（48×64）

| 项 | 设定 |
|---|---|
| 读法 | 一丛低矮、宽扁的幼蕨（`_p` 会被盖在水培机上，**不是**背包图标） |
| 做法 | **模型出形状 + 像素化**（这张图和前三张不同）：手排的两版都被打回「横平竖直」——竖直的茎 + 水平的叶带，像网格。模型（seed 303）给的是**弯曲的叶轴 + 3–4 px 的斜向厚叶**，缩到 48×64 之后仍然是有机的 |
| 生成 | refs = [hydroreed_p 放大版, restoring_fern_l 放大版]；768×1024；提示词强调「低矮宽扁、5 枝粗叶轴、叶片是 3–4 px 的块、不要细丝」 |
| 像素化 | `pixelize2.py --simple --grid 48x64 --margin 2`（3× BOX 直缩，不做多数表决） |
| 摆位 | `place_portrait.py`：内容平移到原版 `_p` 的框里（bbox 底边 y=45，描边占 y=46），水平居中；同时把模型的白亮叶尖折成中青 `B`（否则缩下来是几颗蓝白色方块，像花不像蕨）、并剪掉 1 px 的孤立茎尖 |
| 留白 | 内容 y=13–46、x=1–46（原版两张 `_p` 是 y 11–46、x 1–46） |
| 色板 | `K` `G` `g` `T` `B` `D`（6 色，没用 `L`/`M`） |
| 描边 | 外轮廓 1 px `K` |
| 关键点 | 48×64 上**不要再手排水平叶带**：叶片必须是斜的、叶轴必须是弯的，否则整张图又变成网格；模型稿缩下来后颜色会偏暗，用 `place_portrait.py` 统一压回色板 |

**验收**：内容 bbox ≈ 46×34（y 13–46）；顶部 ≥12 px、底部 ≥17 px 透明；1× 下能看出「弯曲叶轴 + 斜向叶片的丛」，不是横竖网格。

**验收记录**

> 2026-11-22 定稿：`refs/final/restoring_fern_p.png`（48×64、6 色、body 930），来自模型 seed `refs/gen/plant_p_s303.png`。
> 返工记录：手排两版（直茎+水平叶带、弯茎+45° 细叶）都被打回「横平竖直/铁丝网」，因此改用模型定形状 + 像素化 + 摆位；`tools/draw_fern_p.py` 保留但不再使用。
> 与原决定（§9 第 2 条：照 `hydroreed_p` 的浅托盘画）的差异：原版两张 `_p` 都没有托盘，只有植株和根，所以本图也不画托盘，托盘交还给水培机。


## 7. 生成流程（每张图都记 refs / size / seed）

1. 把 refs 统一成「品红底、最近邻放大 16×」（`tools/make_refs.py`），保证模型看到的是像素块而不是柔化图。
2. 尺寸按上表：`16×32 → 512×1024`、`32×32 → 1024×1024`、`48×64 → 768×1024`、`16×16 → 512×512`。
3. `steps=30`，`cfg=1.0`，一次出 4 个 seed，挑一个。
4. 抠品红 → 裁剪到内容 → 按 16 px 网格缩到目标尺寸 → 量化到 §1.1 色板 → 补 1 px 留边与 `(0,0,0,3)` 底。
5. **16×16 的小图（种子、小叶）走「模板重排」**：模型稿只定图标形状与配色，像素按原版同尺寸模板（`dream_cap_seed` / `dream_cap_s`）逐像素排——这样袋型、压边、留白和原版严格一致。
6. 记录：`refs / size / steps / seed / 选中的 png`，写进 `refs/gen/manifest.json`，保证可复现。

## 8. 验收清单（脚本 `tools/check_sprites.py` 逐条跑）

- [ ] 尺寸是 16 的倍数，且与 §0 表一致
- [ ] 内容 bbox 四边 ≥1 px（叶子底边可为 0）
- [ ] 主体像素 alpha=255、无半透明；画布底是 `(0,0,0,3)` 且铺满
- [ ] 所有不透明像素都在 §1.1 的 9 色里
- [ ] 单张 ≤ 8 色
- [ ] 外轮廓有 1 px `#292234`
- [ ] 1× 下能分辨：种子（瓶）、小叶（卷）、标准叶（3 枝）、大叶（5 枝）、立绘（托盘 + 小叶）
- [ ] 与 `dream_cap` 并排时，体量、留白、明暗方向一致
