下层药房  v1.0.1
============================================================

【关于这个模组】
给化学精制机加两条配方，做的都是合法药品。

  · 澄心剂   —— 0.8 ml 梦帽菇萃取液，基础价值 7
    下层区自制的一种廉价抗抑郁剂，通过精细控制梦帽菇萃取液剂量
    达到了安全抗抑郁的效果。
  · 消痛片   —— 0.08 ml 芬太，基础价值 2
    下层区自制的一种廉价强力镇痛剂，通过精细控制芬太剂量
    达到了安全镇痛的效果。

两件都带「医疗品 / 麻醉品 / 烟酒类」标签，但**没有违禁品标签**：
卖出去不会记账、不会招来警察，梦帽菇萃取液和芬太也不再砸在手里。

药效温和是设计，不是缺陷：这两件药不会进入原版「化学品客户反馈」
抽样，所以不会被顾客投诉「药效太弱」，不扣声望、不退货、不要求赔偿。

【怎么用】
1. 化学精制机放在店里，容器槽放一瓶对应液体
   （梦帽菇萃取液 ≥ 0.8 ml，或芬太 ≥ 0.08 ml）
2. 点「配置」，选「澄心剂」或「消痛片」
3. 按「产出」，成品掉进输出格

成色按你实际投进去的液体纯度结算，和原版做药是同一条规则。

【安装】
1. 把整个 Pharmacy-v1.0.1 文件夹放进：
       <游戏目录>/Mods/
   （Steam 版一般是 ...\steamapps\common\Probably Stolen\Mods\）
2. 启动游戏，打开「模组」菜单，找到「下层药房」，点「审核并启用」
3. 启用后可能需要重启游戏一次

【注意】
· 只用官方模组 API，不声明任何能力（files / network / steam），无 Harmony 补丁
· 不影响其他配方，可以和别的化学模组并存
